# 漫画端口长期参考规范

本文件用于漫画端口的长期风格参考。参考来源是用户提供的《看你一眼就会笑》电子书目录资源，以及微信读书常见的成年人治愈插画漫画阅读气质。系统只学习抽象创作方法，不复制任何现成作品、角色、台词、分镜、画面构图或商业 IP。

## 抽象风格方向

- 面向成年人阅读，情绪轻、短、暖，带一点笨拙幽默和日常反差。
- 画面像独立治愈漫画或图文绘本：白底或浅色大留白、简洁线条、低压力阅读节奏、温柔但不幼稚。
- 最终成品应像同一本微信读书治愈漫画摊开后的连续页面：每页一个小场景，少量角色动作，短句直接写在画面里，多页并排看时风格一脉相承。
- 每一辑围绕一个生活瞬间展开，可以使用原创人物、动物、植物、物件、天气、房间、街道、光影等意象。
- 角色关系要松弛，像朋友、室友、同事、陌生人或自我对话，不要强行说教。
- 故事不追求复杂剧情，重点是一个小误会、小安慰、小尴尬、小自嘲、小理解或小反转。
- 对白短，适合漫画气泡；文字克制，不写鸡汤标语，不写儿童寓言，不写网络段子合集。

## 原创与版权边界

- 禁止复刻、改写、近似模仿或暗示 Buddy Gator、盖朵短尾鳄、任何鳄鱼 IP 或其他已有漫画角色。
- 禁止使用现成角色名称、标志性外形、固定配色、招牌表情、经典姿势、经典梗、台词结构或分镜节奏。
- 不要把“短尾鳄、鳄鱼、绿色小动物、圆眼角色”设为默认主角；如需动物，必须重新设计为完全原创且不可识别的角色。
- 不要出现平台名、出版社标识、品牌 logo、水印、二维码、真实封面复刻或可追溯的商业设计元素。
- 可以学习“治愈、短句、留白、轻幽默、日常陪伴”的抽象方法，但所有角色、画面、故事和对白都必须原创。
- 如参考数据库不够支撑具体题材，优先保持白底留白、原创角色、图上短句、轻幽默和同系列统一感，不强行复刻任何参考图。

## 生成优先级

1. 原创性与版权安全优先。
2. 成年人情绪共鸣优先。
3. 系列统一感优先。
4. 简洁、留白、可读性优先。
5. 避免低龄化、模板化和廉价 AI 感。
