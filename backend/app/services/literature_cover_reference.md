# 正统出版封面长期参考规范

本文件用于“正统出版”封面书架的长期参考。参考来源是用户提供的正统出版封面长期参考文件，以及微信读书精选、豆瓣高分文学常见的现代出版封面气质。系统只学习抽象设计规律，不复制任何真实封面、书名、出版社信息、图形、插画、摄影、logo 或排版组合。

## 核心修正方向

- 目标从“淡雅古风水彩”调整为“现代出版级书籍设计”。
- 封面可以文艺，但不能虚；可以留白，但不能淡；可以有诗意，但必须先像一本真正能上架、能被看清、能被点击的现代出版物。
- 重心放在现代出版设计、强平面构成、大标题识别、颜色记忆点、缩略图可读性。

## 抽象设计方向

- 目标不是电商畅销书主图，也不是古风文创插画，而是真正出版社会使用的现代书籍封面。
- 整体应有文学、思想随笔、经典译作或严肃大众读物的出版感：清晰、克制、有设计判断、有缩略图识别度。
- 允许标题很大，但大标题也要像出版设计，不要像短视频海报、PPT 封面或网文广告字。
- 可以使用横排、竖排、超大字、疏朗小字、几何分割、单一插画、抽象色块、建筑局部、城市片段、旅行意象、人物背影、物件隐喻、自然光影或纸张肌理。
- 配色可以有识别度：蓝、绿、黄、红、橙、紫、奶白、黑白等都可以，但必须干净、有层次、有书籍气质。
- 不要默认低饱和，不要默认米灰色，不要灰蒙蒙，不要发黄做旧。
- 画面元素少而准，优先一个主意象或一个版式结构，不堆砌符号。

## 构成判断

- 优先判断这本书更适合哪种现代出版构成：大标题型、色块型、单意象型、抽象图形型、摄影感平面型、留白型或强对比型。
- 只保留一个核心视觉意象，并让这个意象服务于书名和简介。
- 可使用自然、城市、人物剪影、物件、建筑局部、抽象色块、几何形、光影或纸张肌理，但必须少而准。
- 不要堆砌山水、飞鸟、太阳、柳枝、古建筑等古风符号；如必须使用，只能保留一个，并做现代化处理。

## 针对不同书名的微调规则

- 经典文学 / 民间故事：可以保留传统题材，但视觉语言要现代化。不要直接使用柳枝、远山、城墙、飞鸟、太阳、水面等成套古风符号，优先用一个更抽象、更现代的隐喻。
- 社科 / 心理 / 成长：标题要更强，颜色要更有记忆点。主视觉可以是一个物件、一个空间关系、一个抽象结构，不要做成温吞治愈插画。
- 女性 / 情绪 / 治愈：可以柔和，但不能寡淡。允许手绘感和纸张感，但必须有饱和度、标题识别度和收藏感。
- 思想 / 科普 / AI：优先现代几何、抽象图形、数据感、结构感。不要泛用蓝色科技背景，也不要做成 PPT 或信息图。

## 必须避免

- 禁止使用“太阳 + 飞鸟 + 水面 + 柳枝 + 远山 + 纸张肌理”的古风水彩组合。
- 禁止把文学感理解成淡雅、空泛、旧式国风。
- 禁止大面积灰蒙蒙、发黄做旧、低饱和寡淡。
- 禁止文创明信片感、古典诗词插画感、影视海报感、晋江小说封面感、PPT 感、电商商品主图感。
- 不复刻参考文件中任何真实封面，不保留出版社 logo、水印、二维码、价格、真实品牌背书或真实书名残影。
- 不使用可识别真实人物肖像、名人脸或照片脸；人物只能是抽象剪影、背影、符号化小人或非写实插画。
- 不使用厚重 AI 书法字、过细竖排小字、乱码中文、伪中文、英文占位符或廉价生成感插画。

## 生成优先级

1. 真正出版社质感优先。
2. 微信读书书架缩略图识别度优先。
3. 标题层级优先。
4. 平面构成优先。
5. 原创视觉隐喻优先。
6. 版权安全优先。

## 出图后判断标准

- 看缩略图时，书名是否一眼能读出来？
- 画面是否只有一个明确主视觉，而不是符号堆砌？
- 颜色是否有记忆点，而不是灰、淡、旧、虚？
- 它像真实出版社的新书封面，还是像古风水彩明信片？
- 删除副标题后，封面是否仍然成立？如果不成立，说明主视觉太弱。
