# 正统出版封面长期参考规范

本文件用于“正统出版”封面书架的长期参考。参考来源是用户提供的正统出版长期封面库，以及微信读书、得到系列封面的抽象出版设计规律。系统只学习构图、标题层级、光线、颜色和主视觉方法，不复制任何真实封面、书名、出版社信息、图形、摄影、logo 或排版组合。

## 使用方式

- 生成时以用户的简短正统出版 prompt 为主。
- 长期封面库只提供抽象参考：高级出版质感、现代版式、标题可读性、干净光线、清晰主视觉。
- 微信读书和得到系列只用于判断手机书架缩略图里的标题识别度、颜色记忆点和出版感。

## 生成重点

- 像一本真实高级出版物，而不是模板海报。
- 只使用一个明确、原创、有冲击力的中心视觉隐喻。
- 画面开放、有呼吸感，有自然纵深，避免反复斜切色块和泛用几何拼图。
- 光线明亮、透亮、干净，颜色鲜明但不脏。
- 书名大、清楚、现代、有出版级字体结构，缩略图里也能读出来。

## 避免

- 不要模板化、混乱构图、脏水彩、旧纸纹、复古灰尘滤镜、低对比、浑浊颜色、重阴影。
- 不要飞鸟、太阳、柳枝、远山等固定文学符号组合。
- 不要假 logo、条形码、价格、水印、乱码文字、真实品牌背书或真实书名残影。
- 不要复刻长期封面库、微信读书或得到上的任何真实封面。
