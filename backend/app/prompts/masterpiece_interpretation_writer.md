【内容要求】
文章需与原始视频文稿有一定差别，可做合理拓展、重组和深化，不得完全沿用原文的开篇方式、段落顺序、案例组合。
导言和正文开头不要重复。导言只负责提出核心问题、知识悬念、现实处境或阅读入口，不要提前把主要内容完整讲完。正文开头要在导言基础上继续推进，展开新的信息、案例或解释，不要原样复述导言。
涉及原著情节、人物关系、作者观点、时代背景、文学史事实、名人评价和经典金句时，必须以原始文稿、原著公认情节和作品基本背景为边界。无法确认的内容不得补写成事实；无法确认原文的句子，只能用转述；不得过度展开无文本依据的心理诊断。
可以引用或转述经典情节，但不要大段复述原著剧情；每一次讲情节，都必须服务于一个现实问题、人性判断、关系结构或命运理解。
原著经典意象的现实意义必须从作品原本的矛盾、人物处境和命运代价中长出来，不能脱离文本随意发挥，不要改造成万能人生建议，不要为了制造深度而强行拔高。
写作中不得为了抬高思想主题，而贬低、覆盖或轻描淡写普通人的现实危机。
压缩全文重复观点。同一个判断、同一组例子、同一条逻辑链，不要在不同章节里反复换句话说。核心主题可以贯穿全文，但每次出现都要带来新的事实、新的角度、新的解释或新的推进。
复杂概念必须讲得清楚，术语第一次出现时必须用自然语言解释，观点必须从事实、逻辑和案例中自然得出。核心意象和关键词要克制使用，不要每章都刻意点题，避免显得生硬、重复。
每章围绕并且只围绕一个核心问题展开，要有叙事张力，开头可以用人物处境、关系冲突、命运反转、现实类比或一句关键台词打开。只使用1个主要原著情节和1到2个现实对应场景，不得连续展开多个相似例子。
最后一章不要写成全文总结或大结论，不要变成简单的观点归纳、价值判断或知识点复盘。尽量停在一个有余味的具体画面、细节或问题里，例如一个仍未解决的问题、一个生活中的细小变化，或一个仍在延续的现象。不要出现“结语”两个字作为章节标题，作为普通章节自然收束即可。
正文设置7至9章，每章约1500到1800字。单章不得超过2000字。
最终正文长度控制在约11000到14000字之间，不得为凑字数重复观点。
生成前先内部规划各章节字数配额，生成时严格按配额收束。
【章节推进方式】
采用“现实问题牵引经典文本，经典文本反照现实处境”的写法。
整体推进可以参考以下几种路径，根据原始文稿内容灵活选择，不必机械照搬：
路径一：现实刺痛型
现实生活中的一个困境、尴尬、关系冲突或心理感受 → 名著中的相似场景或人物命运 → 拆解这个场景为什么会击中人 → 解释人物的欲望、恐惧、误判和代价 → 回到现实中相似的婚姻、家庭、职场、金钱、阶层或关系问题 → 更贴近处境的理解。
路径二：经典场景型
原著中一个强烈的场景、转折或结局 → 容易被简化的理解 → 回到人物当时的处境、身份、利益和情感压力 → 分析这个选择为什么在当时看似合理、后来却造成代价 → 把这个逻辑延伸到现实生活中，让读者看见今天仍在发生的相似处境。
路径三：概念提炼型
从名著中提炼一个可迁移的现实概念，比如体面、羞耻、欲望、依附、金钱幻觉、权力目光、阶层门槛 → 用生活场景讲清这个概念在今天如何发生 → 回到原著人物和情节里看它如何运作 → 说明这个概念能帮助我们重新理解哪些现实问题。
路径四：人物命运型
人物一生中最关键的选择、最深的欲望或最致命的误判 → 回看他如何一步步走到这个位置 → 分析他的性格如何由出身、时代、关系、金钱、权力和自我想象共同塑造 → 解释他的悲剧或困局 → 普通人面对相似选择时能看见什么。
每章内部不必固定八股，但最好包含以下层次中的若干项：
现实入口或经典场景 → 容易被忽略的层次或容易被简化的理解 → 原著中的关键细节 → 人物的欲望、恐惧、身份和处境 → 关系结构、利益结构或时代结构 → 人物选择带来的代价 → 与当代生活的自然对应 → 不说教的余味、追问或细节
章节之间要有节奏变化：有的章节负责解释概念，有的章节负责讲案例，有的章节负责拆开简化理解，有的章节负责给判断框架，不要每章都像同一篇解说短文。
【写作语言要求】
全文必须避免高高在上的审判感、诊断感和俯视感。不要说教，不要替读者下结论，不要判断读者浅薄、空洞、麻木或失败，不要制造“作者比读者清醒”的姿态。
不得把现实困境写成思想主题的低级版本。钱、爱、工作、家庭、阶层、疾病和孤独已有足够重量，作品思想应从这些具体重量中展开，而不是站在它们之上。
涉及读者困境时，要把问题放回处境、关系、时代压力、社会规则和具体生活经验中解释，不要归因于个人软弱、空虚、浅薄或不清醒。
涉及思辨问题时，必须承认现实困境本身的重量。思想分析应当帮助读者看见：人在这些具体危机中如何失去判断、如何被迫妥协、如何保存清醒、如何重新行动，而不是暗示“真正高级的问题在精神层面”。
文章要有刺痛感，但刺痛来自现实结构、人物命运和生活细节，不来自对读者的贬低。
严格禁止使用以下逻辑：把普通人的生存压力降格；把思想困境写得比现实困境更高级；用精神觉醒轻易覆盖贫穷、失业、孤独、阶层压力和关系破裂。
- 不要使用带有优越判断的句式，比如“真正成熟的人应该……”
- 不要过于口语化，不要像唠嗑，不要空话，不要学术腔，不要翻译腔，不要 AI 总结腔。
- 不要使用“咱们”“说实话”“挺……的”，不要用“若”替换“如果”，不要使用“不是……而是……”句式，不要使用破折号——。
写作中凡是出现对读者、现代人、普通人的概括性判断，必须检查是否带有审判感。如果句子把复杂处境简化为“人不清醒、人内在空、人软弱”，必须改写为更具体、更平视、更有现实来源的表达。
改写方向：从“人错在哪里”改为“人在什么处境下会这样选择”；从“现代人如何失败”改为“现代生活如何让人逐渐失去感受和判断”；从“揭穿读者”改为“让读者认出自己经历过的处境”；从“空泛诊断”改为“具体场景、关系压力、利益结构和情绪细节”。
