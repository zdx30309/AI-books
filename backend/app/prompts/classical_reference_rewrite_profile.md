【参照译写默认范式】
- 这个分类现在只做“原文一段、翻译一段”的干净对照稿，不再参考《菜根谭》类全注全译、注释、点评或讲解体例。
- 参考译本只用于校准释义、术语译法、断句、称谓和语气准确性；如果系统提供“当前原文对应参考译文召回”，必须优先用召回片段校准本段真正含义。默认范本是“菜根谭-中华书局参照范本”时，凡召回片段覆盖到当前原文，一律以中华书局版本的断句、关键字词释义、术语方向和语气密度为第一依据；古汉语词典只负责核对、补足未覆盖字词，不得推翻已命中的中华书局释义。
- 每个原文段落必须先保留原文，再紧跟对应现代白话翻译；不得把全部原文集中放前面，也不得把全部翻译集中放后面。
- 最终正文只允许出现“（原文）”和“（翻译）”两类成对段落；不得输出“【注释】”“【译文】”“【点评】”“【原文定位】”、赏析、解析、译者按、资料说明或圈号注释。
- 原文段必须忠实保留用户输入中的原文，不改字、不删句、不调换顺序；翻译段必须完整覆盖上一段原文的意思。
- 翻译要忠实、准确、自然，补足必要省略关系，但不要扩写成故事、评论、讲义或读后感，也不要写成“这句话的意思是……”这类机翻讲义腔。
- 输出目标不是古典直译腔，而是在中华书局释义基础上转成更大白话一点的现代汉语。普通读者不需要反复琢磨就能明白，语气可以更顺、更生活化，但含义、轻重、比喻方向不能变。
- 可以把古典比喻转换成现代读者更容易理解的说法：例如“欲做精金美玉的人品，定从烈火中煅来；思立掀天揭地的事功，须向薄冰上履过。”不要只写成“想要磨炼出如精金美玉般纯粹的人品，定要经过烈火般的煅烧”；应在保留中华书局义项的基础上写成类似“一个人要想拥有真正过硬的好品格，就必须在现实的严酷考验中不断捶打自己；要想建立了不起的功业，就必须在如履薄冰的压力下，踏踏实实走好每一步，熬过所有的磨难。”这种清楚、自然、有现代白话感的表达。
- 遇到“精金美玉、烈火中煅、掀天揭地、薄冰上履”这类古典意象，先按中华书局译文确定意思，再转成“过硬品格、严酷考验、了不起的功业、如履薄冰的压力和谨慎行动”等更直白的表达；不要停留在照搬意象的逐字翻译。
- 参考译文不能被复制、近似改写或同义替换；如果中华书局召回译文与古汉语词典或模型直觉冲突，优先依据中华书局召回片段，再结合原文上下文做自然白话表达。只有召回片段明显不属于当前原文或未覆盖当前字词时，才用古汉语词典补足。
- 所有翻译落笔前，必须在内部做联网检索交叉验证：围绕当前原文的疑难字词、古今异义、典故、职官制度、人名地名、虚词承接和关键句义，检索专业古籍网站、专业古汉语词典、权威注译资料、出版社/高校/学术类资料等可靠来源，确认其古义和原本意思；不得用百科摘抄、论坛、营销号或现代口语直觉替代专业释义。
- 联网检索只用于校义，不输出网址、来源清单或检索过程；如果专业网站没有可靠结论，必须回到中华书局召回片段、古汉语词典和原文上下文保守处理，宁可保留原词或写得谨慎，也不要编造释义。
- 不能望文生义，不能用现代汉语常见意思拆字理解原文；遇到一个字在现代汉语里很常见，也必须先确认它在该句里的古汉语义项、词性和句内关系，再写白话翻译。
- 关键虚词和承接词不得望文生义：“便觉、始觉、方觉、乃觉、忽觉”里的“觉”通常是“觉得、感到、发觉”，不得译成“导致、造成、引发、致使”；例如“便觉百行皆非”应理解为“便会觉得许多行为都不对”，不能写成“导致百行皆非”。
- 模型不得自行重翻古文：遇到“便、乃、遂、始、方、则、即、须、假、行、觉、见、知、识、容、非、是”等虚词、承接词、判断词或古今异义词，先按中华书局召回片段锁定句内关系；召回片段没有覆盖时，再查古汉语词典。不要为了顺口把并列改成因果、把感知改成结果、把条件改成结论、把比喻改成事实。
- 落笔时内部先做“原文断句 → 中华书局释义对齐 → 联网专业资料交叉验证 → 古汉语词典补缺 → 新白话表达”，不输出这张对齐表。成稿要像充分吃透中华书局译文后的自然复写，而不是模型重新翻译出来的机翻稿。
- 落笔前必须在内部完成“断句 → 关键字词义项 → 参考译文校准 → 联网检索专业网站 → 词典校核 → 自然白话落笔”，但不要输出这个过程。
- 禁止越过参考译文召回和词典校核，直接按现代字面义硬翻。
- 长篇全书要按原文段落顺序逐段覆盖，不漏段、不合并、不拆散；输入有多长，就按同样顺序输出成对原文和翻译。
