【参照译写默认范式】
- 这个分类的目标不是把古文简单翻译成现代汉语，而是参考“经典原文整理、词义注释、现代译文、点评阐发”一体化的处理方式，生成更像古籍全注全译普及读物的白话成稿。
- 成稿必须学习《菜根谭》类参照范本的完整产品形态：前面准确理解原文和版本体例，中间给出必要词义与断句说明，再写现代译文，最后用点评、事例、佐证或人情世故解释拓展理解深度。
- 每个原文条目都要先准确判断主旨、关键词、古今异义、典故、修辞、对偶和因果关系，再组织成一条完整稿；如果只输出一两句直译、一个粗浅故事或一段普通白话，视为不合格。
- 条目内部默认要自然承担四层功能：
  1. 原文原句：条目开头直接呈现原文句子或整理后的原文句，不写“【原文定位】”。
  2. 词义校准：对疑难字词、制度名、典故、成语和古今异义先在理解中处理，必要时在句中自然补足，不做资料堆砌。
  3. 顺译成文：把原文的对偶、转折、因果、比喻和判断转成连贯白话，补足省略主语和逻辑关系，读起来像一段完整说明。
  4. 点评式阐发：在不脱离原意的前提下，追加克制的义理展开、处世判断、历史文化背景或生活场景，让读者明白这一条为什么成立、落在人情世故上意味着什么。
- 可以显式使用“【注释】”“【译文】”“【点评】”等层级；这些标签必须单独成行，标签后的正文另起一行。不要使用“【原文定位】”标签。对短篇寓言、格言、清言、小品、语录体文本，尤其不能只写成一段故事，要让读者看到注译和点评的层次。
- 【注释】最好像正式注本一样使用 ①②③④ 这类带圈编号分条解释；原文中需要说明的关键词也可以对应标出 ①②③④。
- 对《菜根谭》这类格言、清言、小品、语录体文本，不能把每条只译成一句现代话；应当保留格言味、对偶感和警策感，同时把背后的修身、处世、人情、名利、进退、清浊、动静等意思讲透。
- 点评式阐发可以引用常识性历史人物、典籍句意或生活场景作为辅助理解，但不能编造原文没有的关键事实、作者经历、版本结论和确定出处；没有把握时只做保守解释。
- 参考译本只能用于校准释义、术语、断句、语气密度和“原文—注释—译文—点评”的组织方法，不能逐句复刻、不能近似改写、不能把参考译文换词后输出。
- 如果参照译本、用户补充说明和古汉语词典发生冲突，优先依据古文原文、上下文和古汉语词典；不确定的词义宁可保守，不要硬造。
- 长篇全书要逐条覆盖，不漏条、不合并、不把多个独立条目压成一句概括；每条都要做到“能读懂、能明白道理、能看到原文气质和注译点评层次”。
