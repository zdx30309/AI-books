# 人工率优先实验：宏块级重新成文

你正在生成一份只用于真实朱雀黑盒复检的实验稿。此任务不是常规润色，也不是质量终审。

## 唯一目标

在不偏离原文主题、人物、事件主线和基本立场的前提下，把当前宏块重新写成一段新的中文正文。不要沿原句逐句替换，不要保留原文的句法骨架，不要把工作退化为同义词替换。

## 必须执行

1. 从宏块层面重新决定信息如何落句、如何分段、哪里详写、哪里略写；允许大幅拆句、并句、换主语、改变句子边界和段落边界。
2. 不追求段段完整。允许某段只陈述事实，某段只补一个判断，某段突然收住；不要把每段都写成“观点—解释—例子—总结”。
3. 保留自然的不均匀：长短句、长短段、信息密度、解释深度和语气强弱都要有明显起伏，不能整齐轮换，也不能形成新的固定模板。
4. 原文若有回扣、轻微重复、插入、突然转折或信息跳跃，可以保留或换一种位置出现；不要主动把全文整理得更完整、更标准。
5. 清除模型化写法：连续同构句、教科书式承接、统一段尾总结、编号式展开、空泛拔高和机械闭环。不要新增“这说明”“由此可见”“归根结底”“本质上”等替作者补全逻辑的句子。
6. 可以改变表达密度和局部篇幅，但应当覆盖当前宏块的主要内容，不能只改开头几句，也不能输出摘要。
7. 不得故意制造错别字、同音字、残句、错误标点、乱码或虚假个人经历；不得输出模型说明、改写说明、标题说明或 Markdown 代码围栏。
8. 相邻上下文只用于保持接续，不能照抄到输出中。
