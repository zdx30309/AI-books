# 人类参考书双线写作实验

## 目标

本实验只回答一个可验证问题：

> 在不把参考书原文交给改写模型的前提下，把参考书的抽象写作机制和可观察统计画像迁移到一篇已完成文章，能否提高真实朱雀报告首页的官方人工特征比例？

这不是朱雀逆向工程，也不输出“预测朱雀分数”。任何本地指标改善都不能替代真实朱雀 A/B 报告。

## 双线架构

- 从头生成线：上传参考书形成抽象画像，再根据视频或文字素材从头生成文章。
- 原稿改写线：上传参考书形成同一份抽象画像，再对已完成文章进行保序改写。
- 不修改普通文章生成、AI 审稿降率、小说、Epic Novel Engine 或历史已完成任务。
- 参考书原文只用于上传阶段的本地统计和抽象分析，不会进入从头生成或原稿改写 Prompt，也不会写入任务配置。

两条线使用 `information-organization-v2-single-candidate`，但规则不同：

- 原稿改写使用完整的“信息组织规则（最高优先级）”。原稿的段落顺序、观点交叉、信息跳跃、适度重复、举例时机、停止位置和完成度优先于参考画像迁移。
- 从头生成使用该规则的反向生成版本。模型先在内部形成一条自然但不标准化的信息展开轨迹，再沿轨迹写作；不会把每段都补成“观点—解释—案例—结论”的完整单元。
- 两条线都禁止用错别字、病句、标点破坏、虚构经历或无意义重复制造“人味”。

## 可观察画像

`style-probe-v2` 当前记录：

- 句子数、段落数、平均句长和句长标准差；
- 句长变异系数、相邻句长波动、短句/长句比例；
- 平均段长和段长变异系数；
- 逗号、分号、冒号、问号、感叹号、引号密度；
- 标点熵、连接词密度、第一/第二人称密度；
- 字符熵、二元/三元字符熵；
- 三元字符条件熵对应的经验困惑度代理；
- 压缩率、重复四元组比例和汉字词汇多样性。

其中“三元字符经验困惑度”约等于
`2 ** (H(trigram) - H(bigram))`。它只是字符统计代理，不是语言模型困惑度，更不是朱雀内部值。

## 全稿处理

1. “信息组织规则（最高优先级）”是改写的唯一方法，不再叠加全稿重构、统计形状迁移或完成度提升指令。
2. 参考书抽象画像只是不冲突时的语言与节奏软提示；本地数值画像不进入改写目标。
3. OpenAI 只调用一次并只生成一个候选，不再先生成审查计划，也不再自动进行第二轮数值校正。
4. 候选必须保持非空段落数量与顺序，不拆分、合并或移动段落，不在段落之间搬运信息，并保留原稿举例、转换、回扣和停止的位置。
5. 系统不按本地参考距离自动选择候选。候选是否有效只由真实朱雀 A/B 报告判定。
6. Prompt 禁止错别字、病句、机械同义替换、删除标点、伪造个人经历、新增事实、补写过渡、补写总结或提高原稿完成度。
7. 保存原稿/候选哈希、唯一候选全文、调用信息、统计画像、参考距离和四元语面改动率，后两项只用于诊断。

“与参考画像距离下降”只是一项事后诊断，既不参与生成，也不参与选择，更不能解释为人工率上升。

## 真实反馈闭环

实验页要求分别上传原稿和候选稿的朱雀打印 PDF。只有同时满足以下条件，结果才会写入任务的有效观测：

- 两份报告的正文哈希分别匹配本次原稿和候选稿；
- 两份报告均通过正文匹配校验；
- 两份报告首页的人工特征、疑似 AI、AI 特征三项均被可靠识别且合计约为 100%；
- 报告哈希组合未被重复记录。

有效观测记录官方人工特征前后值、真实百分点变化、各统计特征变化、参考距离、语面改动率和模型。后续只有积累多组真实观测后，才允许讨论某个变量方向是否重复有效。

## 首轮使用准则

1. 上传已由朱雀验证为高人工特征、且有合法使用权的完整参考书。
2. 等待参考画像分析完成。
3. 粘贴一篇已有原稿，生成唯一的保序改写候选。
4. 下载候选并分别送检原稿、候选稿。
5. 上传两份打印 PDF，完成真实 A/B 回写。
6. 不根据单篇结果宣称找到朱雀算法；至少需要多篇、跨题材重复观测。

若人工特征没有上升，本轮仍然有价值：它会证明“向这组可观察画像靠近”不足以解释朱雀结果，下一轮应修改假设，而不是继续盲目重复同一 Prompt。
