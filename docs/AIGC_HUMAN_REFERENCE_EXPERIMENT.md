# 人类参考书双线写作实验

## 目标

本实验只回答一个可验证问题：

> 覆盖参考书全部分片并逐层压缩后，把非作者专属的可迁移写作参照与原稿组织规则一起使用，能否提高真实朱雀报告首页的官方人工特征比例？

这不是朱雀逆向工程，也不输出“预测朱雀分数”。任何本地指标改善都不能替代真实朱雀 A/B 报告。

## 双线架构

- 从头生成线：完整抽取 EPUB 等参考文件，按最多 5 万字符的连续分片逐片压缩，再将最终压缩结果与视频摘要、反向组织规则一起完成写作。
- 原稿改写线：使用相同的全分片压缩结果、完整原稿和“信息组织规则（最高优先级）”。
- 不修改普通文章生成、AI 审稿降率、小说、Epic Novel Engine 或历史已完成任务。
- 原书正文不写入任务配置；任务只保存每片压缩结果的最终合并稿、覆盖元数据和调用记录。
- 压缩提示词明确禁止模仿、命名或复刻参考书作者的具体风格，只保留非作者专属的可迁移写作参照。

两条线使用 `information-organization-v4-chunk-compressed-no-style-imitation`，但规则不同：

- 原稿改写使用完整的“信息组织规则（最高优先级）”。原稿的观点顺序、观点交叉、信息跳跃、适度重复、举例时机、停止位置和完成度优先于参考书写作习惯。
- 从头生成使用该规则的反向生成版本。模型先在内部形成一条自然但不标准化的信息展开轨迹，再沿轨迹写作；不会把每段都补成“观点—解释—案例—结论”的完整单元。
- 两条线都禁止用错别字、病句、标点破坏、虚构经历或无意义重复制造“人味”。

## 全稿处理

1. 上传阶段覆盖全部参考书分片；每片先压缩，最后合并。写作模型不直接接触原书，也不接收作者风格画像。
2. 压缩结果只允许包含标点、信息组织、论述推进、句长、用词、词语搭配、语法句式、表达、段落节奏、判断和论证等非作者专属参照；禁止要求“像某作者一样写”。
3. “信息组织规则（最高优先级）”约束原稿思考轨迹，参考书不得成为重新归类、补全逻辑或提高完成度的理由。
4. OpenAI 改写只生成一个候选，不自动二次校正或按本地指标择优。
5. 候选保持事实和观点单元的出现顺序，保留举例、转换、回扣和停止位置；允许在不移动信息顺序的情况下重新切分句子或自然段。
6. Prompt 禁止错别字、病句、机械同义替换、删除标点、伪造个人经历、新增事实、补写过渡、补写总结或提高原稿完成度。
7. 保存原稿/候选哈希、唯一候选全文、调用信息、分片覆盖元数据和四元语面改动率；候选是否有效只由真实朱雀 A/B 报告判定。

## 真实反馈闭环

实验页要求分别上传原稿和候选稿的朱雀打印 PDF。只有同时满足以下条件，结果才会写入任务的有效观测：

- 两份报告的正文哈希分别匹配本次原稿和候选稿；
- 两份报告均通过正文匹配校验；
- 两份报告首页的人工特征、疑似 AI、AI 特征三项均被可靠识别且合计约为 100%；
- 报告哈希组合未被重复记录。

有效观测记录官方人工特征前后值、真实百分点变化、语面改动率和模型。后续只有积累多组真实观测后，才允许讨论某个方向是否重复有效。

## 首轮使用准则

1. 上传已由朱雀验证为高人工特征、且有合法使用权的完整参考书。
2. 等待参考书全部分片完成压缩；旧版任务必须重新上传。
3. 粘贴一篇已有原稿，生成唯一的保序改写候选。
4. 下载候选并分别送检原稿、候选稿。
5. 上传两份打印 PDF，完成真实 A/B 回写。
6. 不根据单篇结果宣称找到朱雀算法；至少需要多篇、跨题材重复观测。

若人工特征没有上升，本轮仍然有价值：它会证明“全分片压缩后的非作者专属写作参照”仍不足以解释朱雀结果，下一轮应修改假设，而不是盲目重复同一 Prompt。

## 独立人工率优先模式

报告驱动审稿页另提供 `human_rate_first`，用于验证外部 SaaS 式“大范围重新成文”是否能显著改变真实朱雀结果。它与上面的参考书双线、正式质量安全编辑及自动终稿闸门完全隔离。

- 自动选中全部非绿色报告片段；相邻片段先合并，再按 2200–5500 字宏块处理。
- 可手动选择 DeepSeek 或 Grok；DeepSeek 使用较高采样温度，Grok 使用页面选择的推理档位。
- Prompt 要求从宏块重新成文，不沿原句逐句替换，并主动打破统一段落功能、统一节奏和标准闭环。
- 不调用事实账本或 Gemini，不使用锚点、段落数、相似度、长度比例和质量评分回滚候选。
- 仍拒绝空响应、完全未改和明显退化为摘要的传输失败；单个宏块失败时保留此前已付费成功的宏块，其余位置沿用原文。
- 原稿、候选、模型、Prompt 版本、费用、处理覆盖和真实报告均独立留档；该模式永远不自动交付终稿。
- 只有真实朱雀报告首页人工特征达到 25% 后，候选才有资格进入单独的质量重建；命中检测不等于质量通过。

该模式的工程目标是得到一次高覆盖、可送检、不会被旧质量闸门回滚的实验候选；它不声称本地已经掌握朱雀算法，也不保证单次实验必然达到 25%。
