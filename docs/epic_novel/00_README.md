# Epic Novel Engine

This folder contains the Epic Novel Engine spec.

Read `EPIC_NOVEL_ENGINE_FULL_SPEC.md` first.

If the full spec is split, read files 01 through 11 in order.

The existing short-form generator is Chapter Draft Writer.

The goal is to add:

- Reference RAG Layer
- Auto Retrieval Planner
- Worldbuilding Atlas Engine
- Mega Bible Compiler
- Storage & State Layer
- Genesis Layer
- Planning Layer
- Execution Layer
- QA Layer
- Production Dashboard
