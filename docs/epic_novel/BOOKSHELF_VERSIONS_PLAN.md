# 1.0与2.0书架实施计划

用户确认先只迁移社科2610。保留原应用、长篇引擎、提示词、模型、封面及漫画链路。

1. 引入配置字段bookshelf_version。新任务按类别固定，社科2610为2.0，其余为1.0；无字段旧任务依据固定工作流推断，Astra Pro社科2610为2.0，其他历史稿为1.0。既有正文、任务ID、阶段和费用记录不改写。
2. 服务端任务列表支持版本过滤和准确分页计数，分类接口支持版本范围。候选链接按版本去重；创建时阻止版本与类别不匹配。修改元数据不能把现有成稿改投另一条生成链，明确重新生成时重新固定目标版本。
3. /bookshelf保留为1.0，新增/bookshelf/v2；详情分别/book/:id与/book/v2/:id。旧链接根据实际版本跳转，新建、轮询、重试、重新生成、导出、删除返回均保留版本归属。
4. 共用组件按版本约束类别、入口、列表和本地筛选状态。2.0仅有社科2610的单条及候选库入口，展示Astra Pro直出步骤；1.0保留其他入口和历史稿。两本已完成测试稿自动显示2.0，不触发再生成。
5. 离线回归覆盖版本推断、创建保护、分页隔离、跨版本去重、再生固定及已有导出。前端类型检查、构建与页面验收；更新实施记录，同步个人Git及服务器。发布前后核对任务/章节元数据与输出文件，不付费生成。
