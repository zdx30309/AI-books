# 编辑交付 0.5 版

按2026年10月13日编辑反馈，在现有视频成稿流程之后新增独立交付层，不重写主笔、一润、二润或格式化流程。只对上线时间之后的视频/参考文章短篇启用；历史书、古文、公版长篇、通用长篇、漫画和Epic canon不切换。

流程：完整视频文案/参考原稿与降AI前完整成稿进行结构框架与素材双维相似度审查 → 朱雀v1默认中文自媒体接口降AI（不传大雅工作模式，不做段落增强） → DeepSeek按优化版双稿指令进行局部纠错 → 交付两份Word。

最终ZIP只包含相似度审查报告和带真实修订的纠错Word。纠错Excel、原稿、降AI文本、模型原始响应、使用量和断点留在服务器供核对，不作为额外最终文件。严重纠错记录仍标红并统计，遵循既有AI_OR_SEVERE_BLOCKS_DELIVERY配置；不改Epic严重项阻断规则。

相似度报告审查对象是降AI前完整成稿，不是最终纠错稿；报告名称、JSON及源/稿hash明确绑定这个阶段。报告高危不自动重写，不等同发布许可；编辑需按报告优先改骨架，修改后应重新审查。未接入人工率或AI特征检测，不承诺人工率>50%或AI特征0%。

评分严格使用S分项40/30/30、M分项30/25/20/25、综合60/40；50%及以上高危，S≥70%始终提示改骨架。模型提供完整语义依据，程序核验原稿/新稿摘录并从表格计数复算，字面层使用autojunk=False及6/8/10/15/20-gram。没有完整两稿、无效依据或响应截断时暂停，不伪造检测结果。原始指令中“结构≥70%不得判安全”与综合硬阈值有冲突，采用其明确的综合阈值和结构兜底提示，不暗改公式。

提示词从两份Word正文及全部表格按XML顺序提取，分别保存到backend/app/prompts/editor_v05/。相似度指令5个表格均已提取，无文本框/图片；纠错指令无表格、文本框或图片。独立transport文件只定义JSON交付形式，模型不负责写文件；完整指令不删减。输入视频文案为纯文本，不宣称DOCX文字提取率100%。

开关：EDITOR_V05_ENABLED=True、EDITOR_V05_START_AT为UTC上线边界、EDITOR_V05_AUDIT_MAX_TOKENS=16384。仍须AI_OR_FINALIZER_ENABLED=True及有效通行证/DeepSeek密钥。密钥不得进入Git。新流程目录editor_v05/与旧ai_or_finalizer/隔离，输入/提示hash变化或不确定的付费请求必须人工核对，禁止覆盖旧断点或重复请求。缺少原稿需补充，不重新付费抓取。

前端沿用Word、相似度审查报告和交付包按钮，不修改两处审稿导航入口。旧书原下载路径兼容保留。0.5只表示编辑交付版本，不表示Epic Novel Engine整体验收完成。

真实验收篇幅保护：0.5通用短篇在一润前检查连续8至10章、实际正文18000至22000词（汉字、英文词、数字组，不含标题目录、标点及参考资料）。不足时复用已保存初稿，通过独立prompt逐章串行补足；原稿及各章请求/响应hash保留，未知付费结果、无效响应不自动重放。编辑阶段不能把已满足的篇幅压成短书，最终纠错后再次检查，不以“完成”状态代替实际篇幅。小编辑块使用按输入长度计算的输出上限，整篇格式化单独使用32768 token；保守预算跨续跑累计，不当作实际账单。

轻抖返回的B站时长缺失或与全文字符数明显不相称时，仅查询既有B站公开metadata适配器校正时长，不重新转写或下载音频。查询失败不继续信任异常时长。真实视频验收发现的2秒误报对应官方28分58秒。

章节目标区间用于引导补写，不作为比原Word更严格的均分章节硬门槛；允许适度长短差异，仍检查全书18000至22000词。全书超过上限时只可撤回已记录的可选增补段落，不截断原段、不删除核心初稿；没有安全方案则暂停。所有省略均记录产物与词数，原响应不覆盖。

预算核算保留既有未知DeepSeek费用的原预留；新的完整相似度/纠错响应保存后，可按官方返回prompt_tokens/completion_tokens、[Flash官方峰值价格](https://api-docs.deepseek.com/quick_start/pricing/)及原10人民币/美元保守系数核定更紧上界。仍按输入未命中缓存与峰值计，不把token核算当实际账单；缺用量/response_id则不释放，重复凭据、异常用量、价格未知或越界均阻断。响应id、实际返回model和原预留均保留，不改变累计20元授权，也不重置原账本。

0.5通用短篇二润直接按正式章节分块并先统一既有加工标记，再检查结构/篇幅；不重复整稿请求，也不把允许的标记变体误判成漏章。真实破坏仍人工暂停。旧题材与非0.5短篇保留原路由。新0.5降AI默认最多3000字符/段，任务可用editor_v05_rewrite_chunk_chars指定更小窗口以减少在途预留，本次预算测试使用1500；不改全局并发、旧书限额或计费率。首次付费分段计划写入manifest，续跑不得因窗口设置变化重分段/重复请求。

引用校验：模型摘录与ASR仅中文句读不同，可唯一定位时替换为真实原文片段；仅影响引用展示，不改变两稿统计文本、数值、程度、计数或评分。删除字词/数字改动不做模糊放行；必要时由操作者逐字核对，提供绑定source/draft/原始响应hash的限定source_quote补丁。原始付费响应从不覆盖，校正投影与原因另存audit_verified_evidence.json；仍无法定位则暂停，不重新调用模型。数据点label可以概述，必须保留可核验的实际source_quote/draft_quote依据，不能要求概述整句等同原句。该审查仍不替代人工事实核对或发布许可。
